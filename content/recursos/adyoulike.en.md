## What it does

Template for the Adyoulike integration. It lets you provide the script URL in the tag configuration and control when it fires through GTM. The code and permissions can be reviewed in the repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
