## What it does

GTM template for the Studyportals pixel. It includes account ID, conversion value, commission, commission percentage and a custom parameter, plus an option for debug logging.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
