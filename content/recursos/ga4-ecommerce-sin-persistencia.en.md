## What it does

Custom variable for retrieving GA4 ecommerce `items` without carrying data over from previous events. Luratic’s documentation explains how it is used and the repository contains the importable variable file.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
