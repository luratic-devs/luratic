## What it does

Unofficial template for loading the Landbot script. Enter the SDK URL in the Landbot script SDK field and manage its activation from GTM. The template code and license are available in the repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
