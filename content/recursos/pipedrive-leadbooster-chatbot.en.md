## What it does

Unofficial template for adding LeadBooster Chatbot. Configure the integration base, Company ID, Playbook UUID and version, then manage loading through GTM container triggers.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
