## What it does

Tag template for Adsmurai Visual Commerce. Its configuration includes the Tracking ID and event options. Alongside the template code, the repository keeps an integration guide for the pixel and the Visual Commerce gallery.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
