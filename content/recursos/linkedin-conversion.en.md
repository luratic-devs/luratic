## What it does

Unofficial template for LinkedIn conversion tracking. It exposes the account Partner ID and Conversion ID so each tag can be associated with the corresponding conversion. The integration file and permissions are public on GitHub.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
