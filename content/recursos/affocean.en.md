## What it does

Tag template for integrating AffOcean through Google Tag Manager. Its fields include Customer ID, Transaction ID and amount, so the transaction information used by the integration can be configured from GTM.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
