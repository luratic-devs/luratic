## What it does

GTM variable for handling referrers coming from Android applications and adapting them to a format Google Analytics can interpret. The documentation explains the use case and the template can be reviewed and imported from the repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
