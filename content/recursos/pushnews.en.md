## What it does

Tag template for adding Pushnews to a website through Google Tag Manager. Configuration focuses on the Site ID for the web-push service. The template file is available in the repository for review and import.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
