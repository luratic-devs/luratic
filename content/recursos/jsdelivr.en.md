## What it does

Tag template for adding resources served from jsDelivr. Its configuration field accepts a path or a full URL. The repository publishes the tag file so you can review what it loads and the permissions it requires.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
