## What it does

Variable for concatenating values and building a text string inside GTM. You can define a separator; the default is a comma. For example, it can compose a page name from several dataLayer variables.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
