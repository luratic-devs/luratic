## What it does

Tag template for E-goi with an event selector in its configuration. The published file lets you review the logic executed for each option and the permissions required inside a web container.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
