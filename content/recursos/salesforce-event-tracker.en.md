## What it does

GTM template for the Salesforce pixel used to measure audiences from email campaigns. It exposes Event ID and Event Type fields. The repository preserves the implementation and permissions for historical reference.

## Historical code

The repository preserves the template file, configuration and license as a historical reference. It is not intended for new implementations.
