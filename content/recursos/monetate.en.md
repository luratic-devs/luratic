## What it does

Template for configuring the Monetate integration from Google Tag Manager. It lets you enter the Monetate URL and adjust the options included in the tag. The repository provides the importable file and its permissions.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
