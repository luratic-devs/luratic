## What it does

Custom variable that returns `document.characterSet`. It can be used by tags or other variables to read the page character encoding and requires no configuration fields.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
