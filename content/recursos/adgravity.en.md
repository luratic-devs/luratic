## What it does

Google Tag Manager tag template for Adgravity. It uses an account identifier as its main configuration field. The importable file and license are available in the public repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
