## What it does

The template lets you enter the Kakao account identifier and select the event type. Its configuration includes predefined events and options for Naver and Payco. The repository contains the tag file and a reference to the pixel documentation.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
