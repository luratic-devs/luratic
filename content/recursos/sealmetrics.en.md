## What it does

Tag template for SealMetrics with tracker and event type selection. It includes account ID, conversion or micro-conversion name, value and advanced options. The code is public so you can review its configuration and permissions.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
