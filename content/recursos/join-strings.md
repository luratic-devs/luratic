## Qué puedes hacer

Variable para concatenar valores y construir una cadena de texto dentro de GTM. Permite definir un separador; el valor predeterminado es una coma. Puede servir, por ejemplo, para componer un nombre de página a partir de distintas variables del dataLayer.

## Código y configuración

El repositorio incluye el archivo de la plantilla. Consulta su documentación y revisa la configuración y los permisos antes de incorporarla a tu contenedor de Google Tag Manager.
