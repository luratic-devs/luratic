## What it does

Unofficial template for loading and initializing Trackingplan using its ID. It supports environment, source alias, debug mode, custom parameters, additional domains and a function for reading a dataLayer with another name. Optional settings are sent only when configured. The repository credits nosDeu for the development.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
