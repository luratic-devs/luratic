## What it does

Cookiebot CMP adaptation that preserves the original Cybot attribution and adds handling for consent stored in the `CookieConsent` cookie. The file lets you configure default values for statistics, preferences and marketing. The improvements are credited to Alfonso, Txema and Brais.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
