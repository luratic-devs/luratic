## What it does

Google Tag Manager variable that returns the number of milliseconds elapsed since the Unix epoch in UTC. It can be used when a tag or integration needs a timestamp for an action.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
