## What it does

GTM template for MailerLite. It exposes account, identifier and integration-type fields. The tag code and permissions are public on GitHub so you can review how the service is added to the site.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
