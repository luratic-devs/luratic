## What it does

Outbrain pixel template with advanced options for conversion and audience measurement. Configure the Marketer ID, select an event and add parameters. The repository contains the tag file and usage references.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
