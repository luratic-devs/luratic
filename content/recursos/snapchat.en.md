## What it does

GTM tag for the Snapchat pixel. It includes the account identifier and an event-name selector, letting you define pixel configuration from GTM while keeping the code available in the public repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
