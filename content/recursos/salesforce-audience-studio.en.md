## What it does

Template for Salesforce Audience Studio exposing Data ID, Namespace ID, path and consent options. It also includes additional configuration, a callback function and console logging. The repository preserves the integration file and license.

## Historical code

The repository preserves the template file, configuration and license as a historical reference. It is not intended for new implementations.
