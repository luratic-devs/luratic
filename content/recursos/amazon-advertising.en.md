## What it does

Unofficial Amazon Advertising template. It exposes integration parameters including `d`, `ex-fargs`, `ex-fch`, `ex-src` and `ex-hargs`. The public file lets you inspect the pixel structure and expected values before adding it to a container.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
