## What it does

Variable that converts a Base64 string back to its text value. Invalid input returns `undefined`. Configure the text to decode directly or through another GTM variable.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
