## What it does

This tag lets you configure the tracking code associated with a HubSpot account. Enter the Account ID and define the appropriate GTM trigger for your implementation. The repository includes the template and a reference to HubSpot tracking code.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
