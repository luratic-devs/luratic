## What it does

Template for Belboon Performance Marketing tracking. It includes advertiser ID and domain, product category, description, goal and conversion identifier, net order value and currency.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
