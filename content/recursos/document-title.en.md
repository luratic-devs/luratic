## What it does

Custom variable that returns `document.title`, making the page title available to tags and other Google Tag Manager variables. The template requires no configuration fields.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
