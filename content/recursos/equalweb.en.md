## What it does

GTM template for adding EqualWeb. It includes `sitekey`, position, menu language and button style fields. The tag code and permissions are public so you can review how the service is loaded.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
