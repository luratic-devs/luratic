## What it does

Template for Belboon Container Tags. It includes an identifier, a page-type selector and parameter options, bringing that configuration into GTM while keeping the implementation available for review in the repository.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
