## What it does

Google Tag Manager variable that receives text and returns its Base64 representation. It is useful when an integration expects that encoding as input. The repository and documentation explain the text field that must be configured.

## Code and configuration

The repository includes the template file. Review its documentation, configuration and permissions before adding it to your Google Tag Manager container.
